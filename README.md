# Korea Bus 3D

시내버스 노선을 3D 지도 위에 그리고, 배차 간격에 맞춰 **움직이는 버스**를 보여주는 웹 지도입니다.
도시를 골라 볼 수 있으며(현재 서울·용인), 도시별 노선 파일만 추가하면 다른 지역도 붙습니다.
마우스 휠로 확대·축소, 우클릭 드래그로 회전·기울이기가 되고, 버스를 클릭하면 노선·다음 정류장·속도를 볼 수 있습니다.

## 바로 실행

빌드 과정이 없습니다. 아무 정적 서버로 `index.html` 을 열면 됩니다.

```bash
# 방법 1 — Node (실시간 모드 프록시 포함)
node server.js            # http://localhost:8080

# 방법 2 — Python
python3 -m http.server 8080
```

GitHub Pages 에 올려도 그대로 동작합니다(시뮬레이션 모드).

## Vercel 배포 (실시간 모드까지)

GitHub Pages 는 정적 파일만 올라가서 시뮬레이션 모드로만 돕니다.
실시간(LIVE)까지 인터넷에서 보려면 API 키를 숨겨 줄 서버가 필요하고, Vercel 이 그 역할을 합니다.
`server.js` 의 어댑터를 `lib/bus-api.js` 로 뽑아 두어서 로컬 서버와 Vercel 함수가 같은 코드를 씁니다.

```
api/health.js          GET /api/health
api/cities.js          GET /api/cities
api/route/[num].js     GET /api/route/143?city=seoul
api/pos/[routeId].js   GET /api/pos/<busRouteId>?city=seoul
lib/bus-api.js         seoul / gbis / tago 어댑터 (server.js 와 공용)
```

1. [vercel.com](https://vercel.com) 에서 GitHub 계정으로 로그인 → **Add New… → Project** → 이 저장소 선택
2. Framework Preset 은 **Other**, Build Command·Output Directory 는 비워 둡니다 (빌드 과정 없음)
3. **Settings → Environment Variables** 에 `DATA_GO_KR_API_KEY` = 공공데이터포털 **Decoding 키** 추가
   (Production·Preview·Development 전부 체크 → 저장 후 **Redeploy** 해야 값이 반영됩니다)
4. 배포 주소로 들어가 오른쪽 **LIVE** 버튼 클릭

CLI 로 올릴 수도 있습니다.

```bash
npx vercel login
npx vercel --prod
npx vercel env add DATA_GO_KR_API_KEY production   # 키 붙여넣기 → 다시 --prod 배포
```

`/api/health` 가 `{"live":true}` 로 나오면 키가 제대로 붙은 것입니다.

### 호출량 주의

공공데이터포털 개발계정 키는 보통 **하루 1,000회** 제한입니다.
화면에서 LIVE 를 켜면 노선 하나당 15초마다 위치를 물어보므로(서울 15개 노선 = 분당 60회)
그대로 두면 한 사람이 20분 만에 하루치를 씁니다. Vercel 배포본은 차량 위치를 CDN 에 10초,
노선 형상을 하루 캐시해서 여러 명이 볼 때 호출을 나눠 쓰지만, **혼자 오래 켜 두는 것 자체가 한도를 태웁니다**.
공개해서 계속 돌릴 거라면 포털에서 운영계정(활용사례 등록)으로 한도를 올리거나,
`js/live.js` 의 `POLL_MS` 를 늘리고 보고 있는 노선만 폴링하도록 좁히는 편이 좋습니다.

## 게임 모드 — 퀵서비스의 달인

오른쪽 🎮 버튼을 누르면 실시간 버스가 다니는 지도 그대로 이어서 게임이 시작됩니다.

1. **탈것 선택**: 오토바이 · 스포츠카 · 버스 · 덤프트럭 · 탱크. 속도·가속·조향·보수 배율이 다르고 의뢰 종류도 달라집니다(버스는 단체 승객, 덤프는 건설 자재, 탱크는 군수 물자). 차체는 `js/game.js` 의 `VEHICLES[].parts` 에 상자 조합으로 정의돼 있어 바퀴·유리·적재함·포탑까지 차종마다 다르게 보입니다.
2. **출발**: 보고 있던 화면 한가운데에서 출발합니다. 카메라가 추적 시점으로 내려옵니다.
3. **의뢰**: 휴대폰이 처음부터 화면 오른쪽에 켜져 있고, 의뢰가 생기면 **바로 그 휴대폰으로 문자가 옵니다**(픽업지·도착지·제한시간·보수). 상담 중에 들어온 다른 의뢰는 휴대폰 아래 "대기 N건" 칩으로 쌓이니 눌러서 바꿔 볼 수 있습니다. 지도의 말풍선도 그대로 클릭할 수 있습니다.
4. **길 안내**: 상단 미션 바와 오른쪽 미니맵에 목적지가 표시되고, 지도에 주황 점선으로 경로가 그려집니다. 경로는 OSRM 공개 라우터(router.project-osrm.org)에서 도로 기준 최단 경로를 받아오며, 응답이 없으면 직선으로 안내합니다.
5. **픽업 · 배달**: 목적지 둘레에 **노란 점선 원**이 그려집니다. 그 원 안에서 시속 16km 아래로 줄이면 자동으로 진행됩니다. 반경은 차 크기에 따라 오토바이 73m ~ 버스 126m 로, 정확히 한 점을 찍을 필요가 없습니다. 제한시간의 60% 안에 끝내면 신속 보너스가 붙습니다.

| 키 | 동작 |
| --- | --- |
| `W` `↑` / `S` `↓` | 가속 / 브레이크·후진 |
| `A` `D` `←` `→` | 조향 (속도가 있어야 돌아감) |
| `Space` | 핸드브레이크 |
| `C` | 시점: 운전석(기울기 84°) → 추적 → 탑뷰 → 자유 |
| 휠 | 시점 각도(위아래 기울기) 조절 |
| Shift + 휠 | 확대 정도 미세 조정 |
| `H` / `M` / `P` | 경적 / 소리 켜고 끄기 / 휴대폰 |
| `Esc` | 휴대폰 닫기 · 게임 종료 |

모바일에서는 화면 아래쪽을 네 구역(좌회전 · 우회전 · 브레이크 · 가속)으로 나눠 터치합니다.

알아둘 점

- 도로망 데이터가 없어서 **지도 위를 자유 주행**합니다(건물·강 위로도 지나갑니다). 도로에 붙여 달리게 하려면 OSM 도로 데이터를 붙이는 후속 작업이 필요합니다.
- 소리는 오디오 파일 없이 Web Audio 로 합성한 엔진음·경적·알림음입니다. 실제 녹음 파일로 바꾸려면 `js/game.js` 의 `EngineAudio` 만 교체하면 됩니다.
- 탈것 모양은 `js/game.js` 의 `VEHICLES[].parts` 에 정의된 상자들을 `render()` 가 쌓아 그립니다. 부품 하나는 `{ x 앞뒤, y 좌우, l 길이, w 폭, b 바닥높이, h 윗면높이, c 색 }` 이고 단위는 m 입니다. 바퀴·유리·포신을 더하거나 빼려면 이 배열만 고치면 됩니다. glTF 모델로 바꾸려면 MapLibre 커스텀 레이어(three.js)로 교체하면 됩니다.

## 실시간 모드(선택)

1. [공공데이터포털](https://www.data.go.kr) 에서 인증키(Decoding 키)를 발급받고, 보고 싶은 지역의 서비스에 **활용신청**을 합니다. 키는 하나로 공용입니다.

| 지역 | 활용신청할 서비스 | 어댑터 |
| --- | --- | --- |
| 서울 | 서울특별시_버스위치정보조회 서비스, 서울특별시_노선정보조회 서비스 | `seoul` |
| 경기(용인 등) | 경기도_버스위치정보 조회, 경기도_노선정보 조회 | `gbis` |
| 그 외 전국 | 국토교통부_(TAGO)_버스위치정보, 국토교통부_(TAGO)_버스노선정보 | `tago` |

2. 키를 환경변수로 넣고 서버 실행

```bash
DATA_GO_KR_API_KEY=발급받은키 node server.js
```

3. 화면 오른쪽 **LIVE** 버튼 클릭

`server.js` 는 브라우저 대신 API 를 호출해 키를 숨기고(CORS 회피), 노선 형상은 24시간·차량 위치는 10초 캐시합니다.
도시별로 어느 어댑터를 쓸지는 `js/data/cities.js` 의 `live` 설정을 따릅니다.

| 엔드포인트 | 내용 |
| --- | --- |
| `GET /api/health` | `{ live, adapters, cities }` |
| `GET /api/route/5000?city=yongin` | busRouteId, 실제 경로 좌표, 정류장 |
| `GET /api/pos/<busRouteId>?city=yongin` | 현재 차량 위치 목록 |
| `GET /api/cities` | 서버가 읽은 도시 설정 |

경기 GBIS 는 차량 GPS 대신 "마지막으로 지난 정류장"만 제공하므로, 서버가 정류장 좌표로 바꿔 주고 화면에서는 정류장 사이를 보간해 움직입니다.

### 도시 추가하기

1. `js/data/cities.js` 의 `SB_CITIES` 에 항목 추가 (이름, 초기 카메라, 실시간 어댑터·도시코드)
2. `js/data/routes.<id>.js` 를 만들어 `window.SB_ROUTE_DATA.<id> = [...]` 로 노선 작성
3. `index.html` 에 그 스크립트 한 줄 추가

TAGO 도시코드는 국토교통부 API 의 `getCtyCodeList` 로 확인할 수 있습니다 (예: 용인 31190, 부산 21, 대구 22, 대전 25, 광주 24).

### 노선 추가하기

도시별 노선 파일(`js/data/routes.<도시>.js`)의 배열에 항목을 추가합니다. `path` 에서 세 번째 값이 있는 점이 정류장입니다.

```js
{
  id: 'r2', num: '2', type: 'trunk', headway: 8, speed: 22,
  from: '기점', to: '종점',
  path: [
    [126.9780, 37.5665, '서울시청'],   // 정류장
    [126.9800, 37.5700],               // 굴곡점
    [126.9827, 37.5700, '종각역'],
  ],
}
```

### 버스 모양 바꾸기

`js/app.js` 의 `pushBuses()` 가 버스 한 대를 차체(아래)와 지붕(위) 두 개의 압출 폴리곤으로 만듭니다.
`G.boxPolygon()` 대신 원하는 형태의 폴리곤을 만들거나, glTF 모델을 쓰고 싶다면 MapLibre 커스텀 레이어(three.js)로 교체하면 됩니다.

## 알아둘 점

- 시뮬레이션 노선 좌표는 실제 경유 도로를 따라 **근사**한 값입니다. 실시간 모드에서는 API 가 주는 실제 형상으로 교체됩니다.
- 경기 GBIS·전국 TAGO 어댑터는 공식 문서 기준으로 작성했고 실제 키로는 아직 검증하지 않았습니다. 응답 형식이 다르면 `server.js` 의 해당 어댑터만 고치면 됩니다.
- 운행 시간·배차는 서울 표준시(KST) 기준으로 계산하므로 해외에서 열어도 서울 시각에 맞춰 움직입니다.
- 지도 타일: © OpenStreetMap contributors, OpenFreeMap / CARTO(대체 지도).

## 하늘 · 가로등 · 이퀄라이저에 대해

**하늘** (`js/sky.js`) 은 지도 캔버스 위에 얹은 2D 캔버스입니다. 하늘의 아래 끝은
MapLibre 가 실제로 지면 그리기를 멈추는 선(`transform.getHorizon()`)에 맞춰서, 그 아래
진짜 도시가 그려지는 자리는 한 픽셀도 덮지 않습니다. 대신 지평선이 화면에 들어와야
하늘이 생기므로 **pitch 68도 아래에서는 아무것도 안 보입니다** — 기본 시점(58도)에서
별을 보려면 휠 버튼 드래그로 위로 더 기울여야 합니다.

| pitch | 하늘 높이 (화면 903px 기준) |
| --- | --- |
| 58도 (기본) | 0px |
| 70도 | 32px |
| 75도 | 140px |
| 85도 (최대) | 344px |

지도를 한 바퀴 돌리면 하늘도 화면 두 폭만큼 흘러갑니다.

**가로등** (`js/citylights.js`) 은 좌표 목록을 따로 갖고 있지 않습니다. 지금 화면에
그려진 벡터 타일의 도로선(OpenMapTiles `transportation` 레이어)을 `queryRenderedFeatures`
로 읽어 일정 간격으로 점을 찍기 때문에, 어느 도시로 옮겨도 실제 도로를 따라 켜집니다.
화면당 최대 900개로 제한하고 지도가 멈춘 뒤에만 다시 계산합니다.

**이퀄라이저는 실제 파형이 아닙니다.** 유튜브 iframe 의 오디오는 다른 출처(cross-origin)라
Web Audio 로 들여다볼 수 없습니다. 재생 중일 때만 음악처럼 움직이는 막대를 그리고
멈추면 가라앉습니다. 플레이어를 화면 밖에 숨기지 않고 패널 안에 작게 두는 것도,
숨긴 iframe 은 브라우저·유튜브 정책에 걸려 재생이 막히는 경우가 있어서입니다.
