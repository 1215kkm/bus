# Seoul Bus 3D

서울 시내버스 노선을 3D 지도 위에 그리고, 배차 간격에 맞춰 **움직이는 버스**를 보여주는 웹 지도입니다.
마우스 휠로 확대·축소, 우클릭 드래그로 회전·기울이기가 되고, 버스를 클릭하면 노선·다음 정류장·속도를 볼 수 있습니다.

## 바로 실행

빌드 과정이 없습니다. 아무 정적 서버로 `index.html` 을 열면 됩니다.

```bash
# 방법 1 — Node (실시간 모드 프록시 포함)
node server.js            # http://localhost:8080

# 방법 2 — Python
python3 -m http.server 8080
```

GitHub Pages 에 올려도 그대로 동작합니다(시뮬레이션 모드).

## 기능

| 기능 | 설명 |
| --- | --- |
| 3D 지도 | MapLibre GL JS + OpenFreeMap 벡터 타일. 건물 3D 압출, 다크/라이트 테마 |
| 노선 15개 | 간선(143·150·273·360·370·400·470·721), 지선(6411·1711·2224), 광역(9401), 심야(N26), 순환(01A 남산), 마을(종로02) |
| 움직이는 버스 | 시간대별 배차 간격(출퇴근 단축·심야 확대), 정류장 정차, 종점 회차, 운행 종료 시 차고지 복귀 |
| 시간 조작 | 하단 슬라이더로 시각 이동, ×1 / ×5 / ×20 / ×60 배속, 실시간(벽시계) 복귀 |
| 검색 | 노선 번호·정류장 이름 검색, 노선 전체 보기·이 노선만 보기, 버스 따라가기 |
| 실시간 모드 | 서울시 버스 위치정보 API 연결 시 실제 차량 GPS + 실제 노선 형상으로 교체 |

단축키: `/` 검색 · `Space` 일시정지 · `D` 테마 · `B` 건물 · `Esc` 닫기

## 실시간 모드(선택)

1. [공공데이터포털](https://www.data.go.kr) 에서 **서울특별시_버스위치정보조회 서비스** 와 **서울특별시_노선정보조회 서비스** 활용 신청 → 인증키(Decoding) 발급
2. 키를 환경변수로 넣고 서버 실행

```bash
SEOUL_BUS_API_KEY=발급받은키 node server.js
```

3. 화면 오른쪽 **LIVE** 버튼 클릭

`server.js` 는 브라우저 대신 API 를 호출해 키를 숨기고(CORS 회피), 노선 형상은 24시간·차량 위치는 10초 캐시합니다.

| 엔드포인트 | 내용 |
| --- | --- |
| `GET /api/health` | `{ live: true/false }` |
| `GET /api/route/143` | busRouteId, 실제 경로 좌표, 정류장 |
| `GET /api/pos/<busRouteId>` | 현재 차량 위치 목록 |

## 구조

```
index.html          화면 골격
css/app.css         UI 스타일
js/data/routes.js   노선 정의 (좌표·정류장·배차·속도)  ← 노선 추가는 여기
js/geo.js           거리·보간·3D 차체 폴리곤 계산
js/sim.js           운행 시뮬레이션 엔진
js/live.js          실시간 API 어댑터
js/app.js           지도 레이어·애니메이션·UI
server.js           정적 서버 + 실시간 API 프록시 (의존성 없음)
```

### 노선 추가하기

`js/data/routes.js` 의 배열에 항목을 추가합니다. `path` 에서 세 번째 값이 있는 점이 정류장입니다.

```js
{
  id: 'r2', num: '2', type: 'trunk', headway: 8, speed: 22,
  from: '기점', to: '종점',
  path: [
    [126.9780, 37.5665, '서울시청'],   // 정류장
    [126.9800, 37.5700],               // 굴곡점
    [126.9827, 37.5700, '종각역'],
  ],
}
```

### 버스 모양 바꾸기

`js/app.js` 의 `pushBuses()` 가 버스 한 대를 차체(아래)와 지붕(위) 두 개의 압출 폴리곤으로 만듭니다.
`G.boxPolygon()` 대신 원하는 형태의 폴리곤을 만들거나, glTF 모델을 쓰고 싶다면 MapLibre 커스텀 레이어(three.js)로 교체하면 됩니다.

## 알아둘 점

- 시뮬레이션 노선 좌표는 실제 경유 도로를 따라 **근사**한 값입니다. 실시간 모드에서는 API 가 주는 실제 형상으로 교체됩니다.
- 운행 시간·배차는 서울 표준시(KST) 기준으로 계산하므로 해외에서 열어도 서울 시각에 맞춰 움직입니다.
