# Korea Bus 3D

시내버스 노선을 3D 지도 위에 그리고, 배차 간격에 맞춰 **움직이는 버스**를 보여주는 웹 지도입니다.
도시를 골라 볼 수 있으며(현재 서울·용인), 도시별 노선 파일만 추가하면 다른 지역도 붙습니다.
마우스 휠로 확대·축소, 우클릭 드래그로 회전·기울이기가 되고, 버스를 클릭하면 노선·다음 정류장·속도를 볼 수 있습니다.

## 바로 실행

빌드 과정이 없습니다. 아무 정적 서버로 `index.html` 을 열면 됩니다.

```bash
# 방법 1 — Node (실시간 모드 프록시 포함)
node server.js            # http://localhost:8080

# 방법 2 — Python
python3 -m http.server 8080
```

GitHub Pages 에 올려도 그대로 동작합니다(시뮬레이션 모드).

## 기능

| 기능 | 설명 |
| --- | --- |
| 3D 지도 | MapLibre GL JS + OpenFreeMap 벡터 타일. 건물 3D 압출, 다크/라이트 테마 |
| 도시 선택 | 왼쪽 위 메뉴에서 전환. `?city=yongin` 처럼 주소로도 지정 가능 |
| 서울 15개 노선 | 간선(143·150·273·360·370·400·470·721), 지선(6411·1711·2224), 광역(9401), 심야(N26), 순환(01A 남산), 마을(종로02) |
| 용인 9개 노선 | 직행좌석(5000·5002·1150), 광역급행(M4101), 일반(10·66·20·820), 마을(15) |
| 움직이는 버스 | 시간대별 배차 간격(출퇴근 단축·심야 확대), 정류장 정차, 종점 회차, 운행 종료 시 차고지 복귀 |
| 시간 조작 | 하단 슬라이더로 시각 이동, ×1 / ×5 / ×20 / ×60 배속, 실시간(벽시계) 복귀 |
| 검색 | 노선 번호·정류장 이름 검색, 노선 전체 보기·이 노선만 보기, 버스 따라가기 |
| 실시간 모드 | 공공데이터포털 키 하나로 서울(TOPIS)·경기(GBIS)·전국(TAGO) 실시간 차량 위치 + 실제 노선 형상 |
| 게임 모드 | 🎮 배달 드라이버 — 탈것 5종, 근처 의뢰 말풍선, 휴대폰 문자 수락, 미니맵, 운전석/추적/탑뷰 시점, 니트로, 건물 충돌·파괴, 합성 엔진음 |

단축키: `/` 검색 · `Space` 일시정지 · `D` 테마 · `B` 건물 · `Esc` 닫기
지도 조작: 휠 확대·축소 · **휠 버튼 드래그** 좌우 회전·상하 기울기 · 우클릭 드래그 · Ctrl+드래그

## 게임 모드 — 배달 드라이버

오른쪽 🎮 버튼을 누르면 실시간 버스가 다니는 지도 그대로 이어서 게임이 시작됩니다.

1. **탈것 선택**: 오토바이 · 스포츠카 · 버스 · 트럭 · 덤프트럭. 속도·가속·조향·보수 배율이 다르고 의뢰 종류도 달라집니다(버스는 단체 승객, 덤프는 건설 자재 등).
2. **출발**: 보고 있던 화면 한가운데에서 출발합니다. 카메라가 추적 시점으로 내려옵니다.
3. **의뢰**: 근처 정류장에 말풍선(💬 품목 · 거리 · 보수)이 뜹니다. 클릭하면 휴대폰 화면에 문자로 픽업지·도착지·제한시간·보수가 오고, 수락하면 배달이 시작됩니다.
4. **길 안내**: 상단 미션 바와 오른쪽 미니맵에 목적지가 표시되고, 지도에 주황 점선으로 경로가 그려집니다. 경로는 OSRM 공개 라우터(router.project-osrm.org)에서 도로 기준 최단 경로를 받아오며, 응답이 없으면 직선으로 안내합니다.
5. **픽업 · 배달**: 목적지 30m 안에서 멈추면 자동으로 진행됩니다. 제한시간의 60% 안에 끝내면 신속 보너스가 붙습니다.

| 키 | 동작 |
| --- | --- |
| `W` `↑` / `S` `↓` | 가속 / 브레이크·후진 |
| `A` `D` `←` `→` | 조향 (속도가 있어야 돌아감) |
| `Shift` | 니트로 부스트 (게이지 소모, 놓으면 회복) |
| `Space` | 핸드브레이크 |
| `C` | 시점: 운전석(기울기 84°) → 추적 → 탑뷰 → 자유 |
| 휠 | 시점별 확대 정도 미세 조정 |
| `H` / `M` / `P` | 경적 / 소리 켜고 끄기 / 휴대폰 |
| `G` / `R` | 유령 모드(건물 통과) / 즉시 수리 |
| `Esc` | 휴대폰 닫기 · 게임 종료 |

### 탈것

| 탈것 | 최고 속도 | 건물 파괴 | 특징 |
| --- | --- | --- | --- |
| 🏍️ 오토바이 | 260km/h | 불가 | 가장 민첩, 내구도가 낮아 크게 튕김 |
| 🏎️ 스포츠카 | 480km/h | 불가 | 압도적 속도, 신속 보너스에 유리 |
| 🚌 버스 | 210km/h | 150km/h 이상 | 단체 승객 의뢰, 보수 높음 |
| 🚚 트럭 | 240km/h | 90km/h 이상 | 큰 짐, 웬만한 건물은 밀고 지나감 |
| 🚛 덤프트럭 | 200km/h | 45km/h 이상 | 철거 전문, 보수 배율 최고 |

니트로를 쓰면 최고 속도가 1.35배까지 올라갑니다.

### 건물 충돌과 파괴

3D 건물 위에서 차 앞머리가 어느 건물 안에 들어갔는지 매 프레임 판정합니다. 한 프레임에 벽을 지나쳐 버리지 않도록 이동 구간을 나눠 검사하므로 480km/h 에서도 통과하지 않습니다.

- **튕김**: 파괴력이 없거나 속도가 모자라면 차가 건물 밖으로 밀려나며 반대 방향으로 반동합니다. 화면이 흔들리고 붉게 번쩍이며, `쿵!` 문구와 파편이 튀고 내구도가 깎입니다.
- **파괴**: 트럭·덤프·버스가 기준 속도를 넘겨 부딪히면 그 건물이 사라지고 낮은 잔해 더미로 무너져 내립니다. 먼지와 파편이 퍼지고 **철거 수당**이 들어옵니다. 6초 안에 연달아 부수면 연쇄 배율이 붙습니다. 높은 건물일수록 더 빠른 속도가 필요합니다.
- **완파**: 내구도가 0 이 되면 그 자리에서 견인·수리하며 수리비 5,000원이 빠집니다. `R` 로 미리 수리할 수 있습니다.
- **유령 모드**(`G`): 충돌을 끄고 건물을 통과합니다. 3D 건물 표시(`B`)를 꺼도 충돌이 없어집니다.

건물을 숨기는 데는 지도 타일이 주는 건물 고유 id 를 씁니다. 타일에 id 가 없는 건물은 잔해만 덮이고 원래 건물이 남을 수 있는데, 이 경우에도 한 번 부순 건물은 다시 막지 않고 그대로 통과합니다.

모바일에서는 화면 아래쪽을 네 구역(좌회전 · 우회전 · 브레이크 · 가속)으로 나눠 터치합니다.

알아둘 점

- 도로망 데이터가 없어서 **지도 위를 자유 주행**합니다. 건물은 막히지만 강·산은 그대로 지나갑니다. 도로에 붙여 달리게 하려면 OSM 도로 데이터를 붙이는 후속 작업이 필요합니다.
- 파괴는 화면에 보이는 지도 위에서만 일어나며, 새로 고치면 건물이 원래대로 돌아옵니다. 실제 지도 데이터는 바뀌지 않습니다.
- 소리는 오디오 파일 없이 Web Audio 로 합성한 엔진음·경적·알림음입니다. 실제 녹음 파일로 바꾸려면 `js/game.js` 의 `EngineAudio` 만 교체하면 됩니다.
- 탈것 모양은 `js/game.js` 의 `render()` 에서 상자 조합으로 그립니다. glTF 모델로 바꾸려면 MapLibre 커스텀 레이어(three.js)로 교체하면 됩니다.

## 실시간 모드(선택)

1. [공공데이터포털](https://www.data.go.kr) 에서 인증키(Decoding 키)를 발급받고, 보고 싶은 지역의 서비스에 **활용신청**을 합니다. 키는 하나로 공용입니다.

| 지역 | 활용신청할 서비스 | 어댑터 |
| --- | --- | --- |
| 서울 | 서울특별시_버스위치정보조회 서비스, 서울특별시_노선정보조회 서비스 | `seoul` |
| 경기(용인 등) | 경기도_버스위치정보 조회, 경기도_노선정보 조회 | `gbis` |
| 그 외 전국 | 국토교통부_(TAGO)_버스위치정보, 국토교통부_(TAGO)_버스노선정보 | `tago` |

2. 키를 환경변수로 넣고 서버 실행

```bash
DATA_GO_KR_API_KEY=발급받은키 node server.js
```

3. 화면 오른쪽 **LIVE** 버튼 클릭

`server.js` 는 브라우저 대신 API 를 호출해 키를 숨기고(CORS 회피), 노선 형상은 24시간·차량 위치는 10초 캐시합니다.
도시별로 어느 어댑터를 쓸지는 `js/data/cities.js` 의 `live` 설정을 따릅니다.

| 엔드포인트 | 내용 |
| --- | --- |
| `GET /api/health` | `{ live, adapters, cities }` |
| `GET /api/route/5000?city=yongin` | busRouteId, 실제 경로 좌표, 정류장 |
| `GET /api/pos/<busRouteId>?city=yongin` | 현재 차량 위치 목록 |
| `GET /api/cities` | 서버가 읽은 도시 설정 |

경기 GBIS 는 차량 GPS 대신 "마지막으로 지난 정류장"만 제공하므로, 서버가 정류장 좌표로 바꿔 주고 화면에서는 정류장 사이를 보간해 움직입니다.

## 구조

```
index.html               화면 골격
css/app.css              UI 스타일
js/data/cities.js        도시 목록·카메라·실시간 어댑터 설정, 노선 종류(색상)
js/data/routes.seoul.js  서울 노선 정의 (좌표·정류장·배차·속도)
js/data/routes.yongin.js 용인 노선 정의
js/geo.js                거리·보간·3D 차체 폴리곤 계산
js/sim.js                운행 시뮬레이션 엔진
js/live.js               실시간 API 클라이언트
js/app.js                지도 레이어·애니메이션·UI·도시 전환
js/game.js               게임 모드 (운전 물리·의뢰·휴대폰·미니맵·길안내·소리)
css/game.css             게임 UI 스타일
server.js                정적 서버 + 실시간 API 프록시 (서울/경기/전국 어댑터, 의존성 없음)
```

### 도시 추가하기

1. `js/data/cities.js` 의 `SB_CITIES` 에 항목 추가 (이름, 초기 카메라, 실시간 어댑터·도시코드)
2. `js/data/routes.<id>.js` 를 만들어 `window.SB_ROUTE_DATA.<id> = [...]` 로 노선 작성
3. `index.html` 에 그 스크립트 한 줄 추가

TAGO 도시코드는 국토교통부 API 의 `getCtyCodeList` 로 확인할 수 있습니다 (예: 용인 31190, 부산 21, 대구 22, 대전 25, 광주 24).

### 노선 추가하기

도시별 노선 파일(`js/data/routes.<도시>.js`)의 배열에 항목을 추가합니다. `path` 에서 세 번째 값이 있는 점이 정류장입니다.

```js
{
  id: 'r2', num: '2', type: 'trunk', headway: 8, speed: 22,
  from: '기점', to: '종점',
  path: [
    [126.9780, 37.5665, '서울시청'],   // 정류장
    [126.9800, 37.5700],               // 굴곡점
    [126.9827, 37.5700, '종각역'],
  ],
}
```

### 버스 모양 바꾸기

`js/app.js` 의 `pushBuses()` 가 버스 한 대를 차체(아래)와 지붕(위) 두 개의 압출 폴리곤으로 만듭니다.
`G.boxPolygon()` 대신 원하는 형태의 폴리곤을 만들거나, glTF 모델을 쓰고 싶다면 MapLibre 커스텀 레이어(three.js)로 교체하면 됩니다.

## 알아둘 점

- 시뮬레이션 노선 좌표는 실제 경유 도로를 따라 **근사**한 값입니다. 실시간 모드에서는 API 가 주는 실제 형상으로 교체됩니다.
- 경기 GBIS·전국 TAGO 어댑터는 공식 문서 기준으로 작성했고 실제 키로는 아직 검증하지 않았습니다. 응답 형식이 다르면 `server.js` 의 해당 어댑터만 고치면 됩니다.
- 운행 시간·배차는 서울 표준시(KST) 기준으로 계산하므로 해외에서 열어도 서울 시각에 맞춰 움직입니다.
